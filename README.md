🪚 Marcenaria Mestre MDF | Móveis Planejados sob Medida

"Transforme seu espaço em uma obra de arte sob medida."

Landing page profissional, fluida e refinada desenvolvida com HTML5, Tailwind CSS, JavaScript (ES6+) e componentes dinâmicos em estilo React, otimizada para máxima conversão de clientes via WhatsApp.

📌 Sobre o Projeto

Este projeto consiste em um site responsivo e de alta performance para uma marcenaria especializada em móveis planejados em MDF.

O design foi concebido sob a filosofia minimalista e elegante da Apple (fundo limpo white/off-white, tipografia marcante com a fonte Outfit & Inter, transições fluidas e detalhes em madeira nobre/amber), transmitindo sofisticação e confiança.

🌟 Diferencial Competitivo

Medição Técnica no Local: Enfatiza o compromisso de medir 100% dos espaços no imóvel antes de fabricar qualquer peça.

Foco em Conversão: Ergonomia total para navegação mobile com botão flutuante inteligente do WhatsApp com pulso dinâmico.

🛠️ Tecnologias Utilizadas (Stack)

HTML5: Estrutura semântica para SEO e acessibilidade.

Tailwind CSS: Estilização moderna, responsividade total (Mobile-First) e suporte a Glassmorphism.

JavaScript (ES6+) / Lógica Dinâmica:

Simulador de orçamento de ambientes por checklist.

Filtros interativos para a galeria do catálogo.

Lightbox/Modal de zoom com acionamento direto ao WhatsApp.

Lucide Icons & Google Fonts: Ícones vetoriais leves e tipografia refinada (Outfit + Inter).

🚀 Como Executar o Projeto Localmente

Clone o repositório:

git clone https://github.com/carloshenriquepalhasantos-hash/marcenaria-mdf.git


Acesse a pasta do projeto:

cd marcenaria-mdf


Abra no navegador:
Basta abrir o arquivo index.html em qualquer navegador (Chrome, Edge, Firefox, Safari) ou rodar via extensão Live Server no VS Code.

🌐 Publicação (GitHub Pages)

Para visualizar este site online:

Vá até as Settings do repositório no GitHub.

Acesse a aba Pages.

Selecione a branch main e salve.

O site estará disponível em poucos minutos.
